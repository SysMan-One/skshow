# SKSHOW -- показать TCP/IP сокеты системы

Показывает TCP и UDP сокеты системы одной таблицей: кто с кем
говорит, в каком состоянии, какой процесс держит сокет и сколько
октетов и пакетов через него прошло.  Таблицу можно сузить по
адресу, порту, протоколу, семейству, состоянию и по имени
процесса-владельца.

Формат:

```
SKSHOW SHOW    [/квалификаторы...]   один снимок, затем выход
SKSHOW MONITOR [/квалификаторы...]   перерисовывать до Ctrl-C
SKSHOW HELP    [тема...]             эта справка
```

Глагол и квалификатор можно сокращать, пока сокращение остаётся
однозначным: MON -- это MONITOR, /INT -- это /INTERVAL.
Квалификатор начинается с косой черты или с двух дефисов, так что
/PMASK и --PMASK -- одно и то же.  Один дефис квалификатором не
является: -lpn=80 отвергается как нераспознанное слово, а не
молча пропускается.

Квалификатор, принимающий список, берёт одно значение или
несколько в скобках; строка показывается, если подходит хотя бы
под одно из них:

```
$ skshow show /state=listen
$ skshow show /state=(listen,estab)
```

Откуда берутся данные: список сокетов читается из
/proc/net/tcp, tcp6, udp и udp6 -- они есть в любом ядре.
Счётчики запрашиваются у ядра через NETLINK; у ядра, собранного
без CONFIG_INET_DIAG, их нет, и в столбцах счётчиков стоит n/a.
У UDP-сокетов счётчиков октетов нет вовсе, там тоже n/a.

Запускайте от root, чтобы видеть владельца каждого сокета.  Без
этой привилегии дескрипторы чужого процесса прочитать нельзя, его
сокеты показываются как ???, а в подвале таблицы сказано, сколько
процессов не удалось посмотреть.

Подробнее -- HELP и имя глагола, квалификатора или раздела:

```
$ skshow help show
$ skshow help pmask
$ skshow help примеры
$ skshow help сообщения ivaddr
```

## SHOW -- показать один снимок и выйти

```
SKSHOW SHOW [/квалификаторы...]
```

Читает сокеты один раз, печатает таблицу с подвалом и выходит.
Вывод можно направить в конвейер или в файл: когда стандартный
вывод -- не терминал, выдаётся только простой текст.

SHOW принимает все квалификаторы, описанные в этой теме.
/INTERVAL и /COUNT принимаются, но ни на что не влияют: цикл
здесь один.

```
$ skshow show /proto=tcp /state=listen
$ skshow show /pmask=sshd > sockets.txt
```

## MONITOR -- перерисовывать таблицу до прерывания

```
SKSHOW MONITOR [/квалификаторы...]
```

Читает сокеты снова и снова, каждые /INTERVAL секунд, и
перерисовывает таблицу на месте.  Ctrl-C останавливает; /COUNT
останавливает после заданного числа циклов.

Строка, изменившаяся с прошлого цикла -- счётчик, длина очереди,
состояние -- или сокет, которого цикл назад не было, показывается
инверсным видео, чтобы живой сокет выделялся на фоне неподвижной
таблицы.  Отключается через /HIGHLIGHT.

Весь экран собирается в памяти и выводится за один раз, поэтому
таблица не мерцает.

```
$ skshow monitor /interval=1
$ skshow monitor /interval=5 /count=12 /nocounters
```

## HELP -- показать справку

```
SKSHOW HELP [тема [подтема...]] [/PAGE] [/NOPAGE]
```

Показывает этот текст.  Без темы -- описание утилиты и список
того, о чём можно спросить.  С темой -- глагол, квалификатор с
косой чертой или без, ПРИМЕРЫ, СООБЩЕНИЯ -- только эту тему.
Сообщение утилиты -- подтема раздела СООБЩЕНИЯ:

```
$ skshow help
$ skshow help monitor
$ skshow help /pmask
$ skshow help pmask
$ skshow help сообщения noprIV
```

Регистр букв значения не имеет.

Тот же текст дают -h, --help, /HELP и /? в любом месте командной
строки, а также запуск образа вообще без аргументов.

На терминале текст останавливается в конце каждой страницы и
ждёт Return; /NOPAGE пускает его без остановок -- то, что нужно
конвейеру.  /PAGE -- умолчание на терминале, в других случаях
игнорируется.

Текст живёт в библиотеке справки skshow_ru.hlb, собранной из
Markdown-описания продукта и установленной в share/help/ru рядом
с образом.  Русская библиотека выбирается, когда локаль
(LC_ALL, LC_MESSAGES или LANG) начинается с ru; иначе -- английская.
Ту же библиотеку читает и браузер HELP:

```
$ vhelp skshow pmask
```

Переменная SKSHOW_HELPLIB называет другую библиотеку.  Когда
библиотеку найти не удаётся вовсе, отвечает краткая сводка,
встроенная в образ, -- короче, но всегда под рукой.

## /LIA -- отбор по локальному IP-адресу

```
/LIA=адрес
```

Показывает сокеты, привязанные к этому локальному адресу.
Литерал IPv4 (192.168.1.10) или IPv6 (fe80::1, ::1).  Семейство
адреса должно совпадать с /FAMILY, если задано и то и другое.

```
$ skshow show /lia=127.0.0.1
$ skshow show /lia=::1
```

## /RIA -- отбор по удалённому IP-адресу

```
/RIA=адрес
```

Показывает сокеты, соединённые с этим удалённым адресом.  Литерал
IPv4 или IPv6, как для /LIA.  У слушающего сокета удалённого
адреса нет, он никогда не подходит.

```
$ skshow show /ria=10.0.0.5
```

## /LPN -- отбор по локальному порту

```
/LPN=порт
```

Показывает сокеты, привязанные к этому локальному порту,
от 1 до 65535.

```
$ skshow show /lpn=22
$ skshow monitor /lpn=443 /interval=1
```

## /RPN -- отбор по удалённому порту

```
/RPN=порт
```

Показывает сокеты, соединённые с этим удалённым портом,
от 1 до 65535.

```
$ skshow show /rpn=53
```

## /PROTO -- отбор по транспортному протоколу

```
/PROTO=TCP
/PROTO=UDP
/PROTO=ALL        (умолчание)
```

Показывает сокеты только одного протокола.  ALL, умолчание,
показывает оба.

```
$ skshow show /proto=udp
```

## /FAMILY -- отбор по семейству адресов

```
/FAMILY=INET      только IPv4
/FAMILY=INET6     только IPv6
/FAMILY=ALL       (умолчание)
```

IPV4 и IPV6 принимаются как другие имена INET и INET6.

```
$ skshow show /family=inet6
```

## /STATE -- отбор по состоянию сокета

```
/STATE=ключевое-слово
/STATE=(ключевое-слово,...)
```

Показывает сокеты, находящиеся в любом из названных состояний.
Ключевые слова -- те же, что у ядра:

```
ESTAB       SYN_SENT    SYN_RECV    FIN_WAIT1   FIN_WAIT2
TIME_WAIT   CLOSE       CLOSE_WAIT  LAST_ACK    LISTEN
CLOSING     UNCONN      ALL
```

UNCONN -- то, что сообщает несоединённый UDP-сокет; это то же
значение, что CLOSE.  ALL в любом месте списка снимает критерий.

```
$ skshow show /state=listen
$ skshow monitor /state=(estab,time_wait)
```

## /PMASK -- отбор по имени процесса-владельца

```
/PMASK=маска
/PMASK=(маска,...)
```

Показывает сокеты, чей процесс-владелец имеет имя, подходящее под
любую из масок.  Имя -- то, которое ядро хранит для процесса: что
ps печатает в столбце COMM, не более пятнадцати символов.

Регистр букв не учитывается: /PMASK=SSHD, /PMASK=sshd и
/PMASK=Sshd отбирают одни и те же строки.

Маска без подстановочных знаков -- подстрока: она подходит, если
встречается в имени где угодно, так что ssh подходит и к sshd, и
к sshd-session.

Маска с подстановочным знаком -- шаблон, который должен покрыть
всё имя целиком:

```
*       любая цепочка символов, в том числе пустая
%       ровно один символ
?       ровно один символ, то же, что %
```

так что ssh* подходит к sshd и sshd-session, но не к
openssh-agent, а ssh? -- только к sshd.

Командный интерпретатор может раскрыть * или ? сам, раньше
утилиты; при сомнении берите маску в кавычки.  Скобки списка по
той же причине лучше тоже закавычить.

Берутся не более восьми масок; остальные пропускаются, о чём
говорит сообщение TOOMANY.

```
$ skshow show /pmask=nginx
$ skshow show /pmask=(nginx,redis,postgres)
$ skshow show '/pmask=ssh*'
$ skshow monitor /pmask=java /interval=2
```

## /COUNTERS -- запрашивать у ядра счётчики

```
/COUNTERS         (умолчание)
/NOCOUNTERS
```

Запрашивает у NETLINK счётчики октетов и пакетов каждого
TCP-сокета.  Это умолчание.  /NOCOUNTERS пропускает запрос: в
столбцах счётчиков стоит n/a, а таблица обходится дешевле на
машине с многими тысячами сокетов.

Если заданы оба -- побеждает последний.

```
$ skshow monitor /nocounters /interval=1
```

## /HIGHLIGHT -- выделять изменившиеся строки

```
/HIGHLIGHT        (умолчание)
/NOHIGHLIGHT
```

В MONITOR показывает инверсным видео каждую строку, отличную от
того, какой она была в прошлом цикле: изменился счётчик, длина
очереди или состояние, либо сокет только что появился.  В первом
цикле ничего не выделяется -- сравнивать не с чем, -- и ничего не
выделяется, когда вывод не терминал.  /NOHIGHLIGHT выключает
выделение.

```
$ skshow monitor /nohighlight
```

## /INTERVAL -- интервал обновления MONITOR

```
/INTERVAL=секунды     (умолчание 3)
```

Сколько MONITOR ждёт между двумя циклами, от 0 до 86400 секунд.
Ноль превращает MONITOR в один снимок, как SHOW.

```
$ skshow monitor /interval=1
```

## /COUNT -- число циклов MONITOR

```
/COUNT=число          (умолчание 0, без ограничения)
```

Сколько циклов выполняет MONITOR, прежде чем выйти сам.  Ноль,
умолчание, -- до Ctrl-C.

```
$ skshow monitor /count=10 /interval=6
```

## /TRACE -- диагностический вывод

```
/TRACE
/NOTRACE          (умолчание)
```

Заставляет утилиту рассказывать, что она делает: какие файлы
читает, что отвечает NETLINK, где найдена библиотека справки.
Диагностика идёт в стандартный поток ошибок или в файл журнала,
если задан /LOGFILE, и никогда -- в таблицу.  SIGUSR1
переключает трассировку у работающего MONITOR.

```
$ skshow show /trace /pmask=sshd 2> trace.txt
```

## /LOGFILE -- направить диагностику в файл

```
/LOGFILE=файл
```

Называет файл, принимающий диагностику и сообщения утилиты вместо
стандартного потока ошибок.  Сама таблица всегда идёт в
стандартный вывод.

```
$ skshow monitor /logfile=/tmp/skshow.log /trace
```

## /LOGSIZE -- ограничить размер файла журнала

```
/LOGSIZE=октеты       (умолчание 0, без ограничения)
```

Перематывает файл журнала на начало, как только он перерастёт
столько октетов, чтобы MONITOR, оставленный на дни, не заполнил
диск.  Имеет смысл только вместе с /LOGFILE.

```
$ skshow monitor /logfile=/tmp/skshow.log /logsize=1000000
```

## /PAGE -- выдавать справку постранично

```
/PAGE             (умолчание на терминале)
/NOPAGE
```

Относится только к глаголу HELP.  На терминале текст
останавливается в конце каждой страницы и ждёт Return.  /NOPAGE
пускает его без остановок -- то, что нужно конвейеру или
перенаправлению; там текст не разбивается на страницы, что бы ни
было задано.

```
$ skshow help /nopage | less
```

## Вывод -- как читать таблицу

Одна строка на сокет, в порядке файлов /proc: TCP по IPv4, TCP
по IPv6, UDP по IPv4, UDP по IPv6.  Столбцы:

```
Proto         TCPv4, TCPv6, UDPv4, UDPv6
Local         локальный адрес и порт
Remote        удалённый адрес и порт; *:* когда его нет
State         состояние сокета, как его пишет /STATE
PID           процесс, держащий сокет
Process       его имя; ??? когда прочитать не удалось
RxQ, TxQ      очереди приёма и передачи, октеты
RxBytes       принято октетов
TxBytes       отправлено октетов
RxPkts        принято пакетов
TxPkts        отправлено пакетов
```

Строка подвала называет время снимка, число показанных строк и
действующий отбор.  Вторая строка подвала, когда нужна, говорит,
сколько процессов не удалось посмотреть за недостатком
привилегий.

Счётчики -- те, что ядро ведёт для TCP-сокета; у ядра без
CONFIG_INET_DIAG их нет, у UDP их нет тоже -- там стоит n/a.

## Примеры

Слушающие TCP-сокеты:

```
$ skshow show /state=listen /proto=tcp
```

Что держит пара серверов на loopback, в любом регистре имён:

```
$ skshow show /lia=127.0.0.1 /pmask=(NGINX,redis)
```

Все сокеты, связанные с SSH, по шаблону:

```
$ skshow show '/pmask=ssh*'
```

Десять обновлений с шагом две секунды, без обращения к NETLINK:

```
$ skshow monitor /interval=2 /count=10 /nocounters
```

Наблюдать за нагруженной машиной, живые строки выделены:

```
$ skshow monitor /interval=1
```

IPv6-сокеты, установленные или ожидающие закрытия:

```
$ skshow monitor /family=inet6 /state=(estab,time_wait)
```

Справка по квалификатору и вся справка без постраничного вывода:

```
$ skshow help pmask
$ skshow help /nopage > skshow-help.txt
```

## Сообщения -- что говорит утилита и что делать

Сообщение утилиты выглядит так:

```
%SKSHOW-E-IVADDR, 10.0.0 is not an IPv4 or an IPv6 address, qualifier /LIA
```

SKSHOW -- имя средства, буква -- серьёзность: S успех,
I информация, W предупреждение, E ошибка, F фатальная ошибка,
а IVADDR -- имя сообщения.  Все сообщения идут в стандартный
поток ошибок или в файл журнала, если задан /LOGFILE.

Служба командной строки добавляет собственные сообщения: о
неизвестном глаголе или квалификаторе, о сокращении, подходящем к
двум из них, о значении не того вида.  Прочитайте строку,
исправьте написание, принятые имена -- в HELP.

Утилита завершается с кодом успеха, когда команда выполнена или
справка показана, и с кодом ошибки, когда командная строка
отвергнута или выполнение не удалось.

### AMBIGVERB -- сокращение подходит к нескольким глаголам

```
%SKSHOW-E-AMBIGVERB, x is an ambiguous verb name
```

Тема, данная HELP, -- сокращение, подходящее более чем к одному
глаголу.  Наберите больше букв.

### CONFQUAL -- два квалификатора противоречат друг другу

```
%SKSHOW-E-CONFQUAL, /LIA and /FAMILY cannot be given together as they stand
```

Адрес IPv6 задан вместе с /FAMILY=INET, или адрес IPv4 -- с
/FAMILY=INET6.  Уберите /FAMILY или согласуйте его с адресом.

### IVADDR -- не IP-адрес

```
%SKSHOW-E-IVADDR, 10.0.0 is not an IPv4 or an IPv6 address, qualifier /LIA
```

Значение /LIA или /RIA -- не литерал IPv4 и не литерал IPv6.
Имя хоста не принимается: сначала найдите адрес и задайте его.

### IVKWD -- не ключевое слово квалификатора

```
%SKSHOW-E-IVKWD, tcp6 is not a keyword of the qualifier /PROTO
```

Значение /PROTO, /FAMILY или /STATE -- ни одно из ключевых слов,
которые принимает квалификатор, либо сокращение, подходящее к
двум из них.  Список -- в теме квалификатора.

### IVNUM -- не число

```
%SKSHOW-E-IVNUM, 3s is not a number, qualifier /INTERVAL
```

Значение числового квалификатора не удалось прочитать как число.
Задайте простое десятичное число; секунды и октеты единиц
измерения не несут.

### NOPRIV -- не суперпользователь

```
%SKSHOW-W-NOPRIV, running as UID 1000, an owner of a foreign socket is shown as ???
```

Утилита работает без привилегии читать дескрипторы других
процессов, поэтому не может сказать, кто держит большинство
сокетов.  Таблица показывается всё равно.  Запустите от root,
через sudo, чтобы видеть каждого владельца.

### NOTOPIC -- нет описания по теме

```
%SKSHOW-E-NOTOPIC, sorry, no documentation on foo
```

HELP спросили о теме, которой нет в библиотеке: не глагол, не
квалификатор, не раздел.  Спросите HELP без темы, чтобы увидеть,
что есть.

### RANGE -- число вне диапазона

```
%SKSHOW-E-RANGE, /LPN=70000 is out of the 1 ... 65535 range
```

Значение числового квалификатора вне разумного: порт -- от 1 до
65535, интервал -- от 0 до 86400 секунд, счётчик циклов и размер
журнала -- от 0 и выше.

### SYNTAX -- командная строка отвергнута

```
%SKSHOW-E-SYNTAX, type "skshow help" for a command summary
```

Служба командной строки отвергла команду и сказала почему строкой
выше: неизвестный глагол или квалификатор, пропущенное значение,
одиночный -имя.  Исправьте ту строку.

### TOOMANY -- слишком много значений в списке

```
%SKSHOW-W-TOOMANY, too many /PMASK values, only the first 8 are used
```

/PMASK дано больше масок, чем утилита хранит.  Используются
первые восемь, остальные пропущены.  Шаблон с * может заменить
несколько из них.
